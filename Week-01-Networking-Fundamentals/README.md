## Cisco Packet Tracer

A basic network topology was implemented using:

**PC → 2960-24TT Switch → 2911 Router**

The configured network included:

- PC: `192.168.1.10`
- Subnet Mask: `255.255.255.0`
- Default Gateway: `192.168.1.1`
- Router GigabitEthernet0/0: `192.168.1.1`

Connectivity between the PC and router was verified using a successful ping test.
