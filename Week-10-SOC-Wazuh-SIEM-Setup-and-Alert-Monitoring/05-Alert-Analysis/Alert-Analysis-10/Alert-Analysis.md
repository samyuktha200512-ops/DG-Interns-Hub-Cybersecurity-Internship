## 4. Detailed Investigation: Google Updater Registry Deletion

### Initial detection

Wazuh generated two related Syscheck alerts:

- Rule 751 – Registry Value Entry Deleted.
- Rule 597 – Registry Key Entry Deleted.

The affected registry path was:

`HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\GoogleUpdaterService157.0.8089.0`

The deleted value was `Type`, with data type `REG_DWORD`.

The alerts were recorded on 13 November 2026 at approximately 03:09 UTC.

### Investigation steps

1. Reviewed the Wazuh alert records and registry path.
2. Checked the Windows Security log for Event ID 4657. No matching events were found.
3. Checked whether Google Updater services were still present.
4. Found two Google Updater services for version `159.0.8140.0`, both stopped with automatic startup configuration.
5. Checked the current updater executable's Authenticode signature. The signature status was valid.

### Findings

The deleted registry key referred to an older Google Updater version (`157.0.8089.0`), while the currently configured services referenced version `159.0.8140.0`.

This is consistent with possible updater version cleanup. However, the exact cause of the registry deletion could not be confirmed from the available evidence.

### Final assessment

**Classification:** Unexplained registry deletion; likely routine software version cleanup, but not conclusively verified.

No confirmed malicious activity was established. Further review would be appropriate if similar unexpected registry deletions recur.

## 5. Alert Severity Interpretation

| Level | Interpretation in this lab |
|---:|---|
| 3 | Low-severity informational or routine activity |
| 5 | Moderate-severity event requiring contextual review |
| 7 | Higher-priority integrity change requiring investigation |
| 8 | High-severity account-related security event requiring analyst review |

A Wazuh severity level indicates alert priority, not proof that an attack occurred.

## 6. Analyst Observations

- Wazuh successfully detected Windows account lifecycle events.
- Syscheck detected registry changes on the Windows endpoint.
- File Integrity Monitoring detected both file creation and modification.
- Routine Windows events were also collected and displayed.
- Investigation of the Google Updater alerts demonstrated the importance of checking surrounding system context instead of treating every alert as malicious.
- The absence of Event ID 4657 limited independent Windows audit corroboration.

## 7. Conclusion

The lab demonstrated how Wazuh collects, categorizes, and prioritizes security events from a monitored Windows endpoint. The investigation combined alert details, Windows service information, registry paths, and executable signature verification.

The results show the importance of correlating multiple sources of evidence before determining whether an alert represents malicious activity, authorized administration, or routine system behavior.
